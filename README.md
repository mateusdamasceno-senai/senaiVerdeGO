# 🍃 VerdeGO! - Mobilidade Sustentável

Aplicação web completa com landing page interativa, calculadora de CO₂, painel de segurança ADAS e protótipo de dashboard B2B.

## 🚀 Como hospedar no Render gratuitamente:

1. Acesse o painel do [Render](https://render.com).
2. Clique em **New +** e selecione **Web Service**.
3. Conecte sua conta do GitHub e selecione este repositório.
4. Preencha as configurações do projeto:
   - **Environment:** `Node`
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
5. Clique em **Create Web Service**.

Pronto! O Render detectará automaticamente o `server.js` na porta informada e disponibilizará sua aplicação online.
